# Student churn analysis DASHBOARD

## Project Overview

This project focuses on analyzing student engagement and predicting student churn using data analysis, machine learning, and Power BI.

The objective is to identify factors associated with student churn, understand engagement patterns, and provide actionable insights through an interactive dashboard.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost
- SHAP
- Power BI
- Excel

## Dataset

- Records: 8,558
- Features: 24
- Target: Student Churn

The dataset was cleaned and prepared before performing exploratory data analysis and machine learning.

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Analysis
4. Data Visualization
5. Machine Learning Model Development
6. Model Evaluation
7. Explainable AI using SHAP
8. Power BI Dashboard Development

## Machine Learning Models

The following models were evaluated:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Random Forest
- XGBoost

XGBoost achieved a PR-AUC of approximately 0.87 during model evaluation.

## Explainable AI

SHAP (SHapley Additive exPlanations) was used to understand feature importance and identify which variables contributed to the model's churn predictions.

## Power BI Dashboard

An interactive Power BI dashboard was created to analyze student churn and engagement patterns.

The dashboard includes:

- Overall student metrics
- Churn analysis
- Engagement analysis
- Risk segmentation
- Age-group analysis
- Trend analysis
- Interactive filters and slicers

## Key Objectives

- Identify students at higher risk of churn
- Understand factors affecting student engagement
- Analyze churn patterns across different student segments
- Build a predictive model for churn
- Present findings through an interactive business dashboard
